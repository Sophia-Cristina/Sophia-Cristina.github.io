~*~ JAVASCRIPT UTILS ~*~

JSUtils is a collection of small JavaScript utilities built on top of JSHeaders. These include calculators, plotters, mathematical tools, logic tools, and other simple interactive programs that may be useful for practical purposes.
The utilities here are designed to work in two ways: they can be used directly as small programs, and they can be imported and reused by larger applications. Smallapps that may be imported for modularity, BiggerApps that may compose multiples SmallApps, StudyApps, and [other projects] can build upon the tools provided here instead of implementing the same functionality again. That also means that if you get the source-code of this page, you can basically use it in a kind of an API.
Because of this, JSUtils is also part of the programming structure of this website. JSHeaders provide the lower-level classes and functions, JSUtils combines them into useful tools, and higher-level applications can combine those tools into more complex software.

Most of the projects listed here are translations of C++ and Ruby programs that I have already made. I list them even when their JavaScript versions are not finished yet. If an item does not have a link, it simply means that I have not translated it to JavaScript yet.

The programs on this page are primarily intended to be interactive tools rather than educational material. For programs specifically designed to teach or demonstrate concepts from a particular field, see the corresponding StudyApps page. For example, a simple CPU emulator may exist in JSUtils as an interactive tool, while a CPU simulator specifically designed to teach Computer Science concepts would belong in StudyApps → Computer Science.

The source code is also part of the purpose of this page. These are relatively small programs intended to be inspected, reused, and learned from. Most browsers allow you to inspect the source code by right-clicking the page and selecting "View Page Source".
In short, JSUtils is the utility layer of the website: small programs built from JSHeaders that can be used independently or become building blocks for larger applications.
