~*~ TRIANGLE PLOTTER ~*~

Two classes, one class the mathematical definition fo a triangle itself. Set 'a' and 'b' sides and 'gamma' angle (the one between 'a' and 'b').
The constructor automatically calculates all proprieties of the triangle.

Then it have a triangle plotter class, which is self-explanatory.
You can use 'bool' variables ('checkbox' in this user interface) to define what propriety of the triangle will be draw, and if there will have text info about it.
If you set a scale based on your "pixels per cm", which you can calibrate in this page: HERE; then you can overlay a paper over the screen to have an accurate enough physical drawing.
