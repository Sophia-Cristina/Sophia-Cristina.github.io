~*~ MY BINARY WORDS CIRCLE FRACTAL ~*~

This fractal is based on a system I devised in which new binary digits are appended to what I call "words", generating every possible combination of 0 and 1 for each iteration.

For example:
Iteration 1 = { 0, 1 }
Iteration 2 = { 0, 1, 00, 01, 10, 11 }
Iteration 3 = { 0, 1, 00, 01, 10, 11, 000, 001, 010, 011, 100, 101, 110, 111 }

The words belonging to each iteration are then assigned positions around a circle according to a score function. The score is calculated from the binary structure of each word, with the current system giving greater weight to the "up" and "right" directions. The words of each individual iteration are therefore ordered according to their scores and distributed around the circle.

This produces an infinite sequence of binary words in which words with related structures can occupy relatively close positions. For example, 111 tends to be positioned near 1111, which in turn tends to be positioned near 11111.

The original idea, however, did not begin as a fractal. I originally developed the underlying logical system for representing concepts from a single source through symmetrical and progressively subdivided directions. For example:
Night and Day → Night, Midnight, Day, Noon → ...

Turning this system into a fractal was a recreational mathematical application that I later discovered could be constructed from the same principles.

The particular score function used here is based on a conventional spatial interpretation in which "above" represents something higher and "below" something lower, while "left" represents going backward and "right" represents going forward. This is why the current score function gives different weights to the vertical and horizontal components. This is only one possible definition, however. The fractal can be constructed with other score functions as long as the function provides a unique, ordered position for each word.

A mere sum of 'sin' and 'cos' would lead to:
 * Two points with value '1': sine(pi*0.5) and cos(0); and two with value '-1': cos(pi) and sin(pi*1.5);
 * Two points with value '0', at sides symetric to 'pi*3/4'.;
So the mathematical idea that inspired the fractal is: finding a way to create an order from values that can cancel each other.
There is more issues related to symmetry. and so i used this score system as one of the possible ways to map each point in a circle.
One can use other functions and score systems to create different colors for the fractal.

Notes:

* In few iterations it can become heavy to render, not because the math, which is super simple, but, because each circle is painted as a new 'image data' and you need a canvas of a very big area to be able to see each cell.
 * At 'Iteration = 16' and 3400^2 area, 16-cores took about 15 seconds to render. On older computers, it may push the RAM a bit.
 * 'Iteration = 7' and area 1142^2 and 'Iteration = 8' and 2416^2 area, seems to be correctly filled and with correct colors.
  * This a sample for reference for you to be aware of how much the canvas size increase per iteration.
* If the image size is too small, the flood-fill operation may fail to fill a cell correctly or may fill an adjacent cell. Increasing the image size gives the cells more space and reduces this problem.
* To avoid discrepancies between the image size and the circle radius, use r = size * 0.5 - 1. You should not worry about this in this page, since it is done automatically, but you should take that in mind if you end up copying this code.

// HIGHER THE SCORE, HIGHER THE VALUE FOR A BINARY WORD:
// * Vertical axis is stronger than horizontal axis;
// * More to the top and more to the right = more score;
double BinaryWordsCircleScore(double rad)
{
	double Score = 0;
	const double Norm = sin(PI * 0.25) * 1.5 + cos(PI * 0.25) * 0.625; // = 1.50260191
	const double Sin = sin(rad), Cos = cos(rad);
	Score += Sin; Score += Cos * 0.5; 
	if (Sin > 0) { Score += 0.5 * Sin; } if (Cos > 0) { Score += 0.125 * Cos; } // "Up" and "Right" give higher score
	Score /= Norm;
	return (Score);
}


CImg<uint8_t> PrintBinaryWordCircle(uint16_t Size, int r, int Iter, bool RandomColor, bool LRGB, Point3D<uint8_t> RGB)
{
	CImg<uint8_t> MainImg(Size, Size, 1, 3, 0), CircI;
	uint32_t Mid = floor(Size * 0.5);
	double Div, SubDiv, rad, Line, rRatio = 1.0 * r / Size;
	std::vector<uint8_t> BinWords = ysxFRACTAL_BinaryWordsSeq(Iter);
	std::vector<uint8_t> BinArea = ysxFRACTAL_BinaryWordSeqArea(Iter);
	for (size_t n = BinArea.size() - 1; n > 0; --n) { BinArea[n] -= BinArea[n - 1]; }
	Point3D<uint8_t> nRGB = RGB;

	uint32_t cSize = 0, MidS, cr, s, s2, Count = 0;
	uint32_t Wordset, WordSize;

	for (uint32_t c = Iter; c > 0; --c)
	{
		cSize = (Size / Iter) * c;
		MidS = cSize * 0.5; cr = rRatio * cSize; s = BinArea[c - 1]; s2 = pow(2, c);
		CircI = CImg<uint8_t>::CImg(cSize, cSize, 1, 3, 127);
		uint8_t cclr[] = { RGB.x * 0.67, RGB.y * 0.67, RGB.z * 0.67 };
		CircI.draw_circle(MidS, MidS, cr, cclr, 1, 1);

		cclr[0] = RGB.z; cclr[1] = RGB.y; cclr[2] = RGB.x;
 		if (c > 1) { ysxCIMG_DRAW_RadiusPolygon(CircI, cr, MidS, MidS, 0, s, 0, 1, cclr); }
		cclr[0] = RGB.y; cclr[1] = RGB.z; cclr[2] = RGB.x;
		ysxCIMG_DRAW_RadiusPolygon(CircI, cr, MidS, MidS, 0, s2, 0, 1, cclr);

		Div = TAU / s2;
		rad = 0; std::vector<Point<double>> Scores;
		for (uint32_t n = 0; n < s2; ++n) { Scores.push_back({ rad, BinaryWordsCircleScore(rad) }); rad += Div; }
		if (!Scores.empty()) { ysxSORT_QuickSortPty(Scores, 0, Scores.size() - 1); }

		Wordset = ysxARITH_SumntoPowIniEnd(2, 1, c - 1);
		for (uint32_t Word = Wordset; Word < Wordset + s2; ++Word)
		{
			size_t WordSize = BinWords[Word].size();
			if (RandomColor) { RGB.x = rand() % 256; RGB.y = rand() % 256; RGB.z = rand() % 256; }
			for (int Char = 0; Char < WordSize; ++Char)
			if (LRGB)
			{
				Line = 1.0 * (Word - Wordset) / s2;
				if (BinWords[Word][0] == '0') { ysxCOLOR_LinearRGB(0.5 + Line, 1, 1, (uint8_t*)&RGB); }
				else { ysxCOLOR_LinearRGB(Line, 1, 1, (uint8_t*)&RGB); }
			}
			WordSize = BinWords[Word].size();
			for (uint32_t Char = 0; Char < WordSize; ++Char)
			{
				nRGB = RGB;
				if (BinWords[Word][WordSize - 1 - Char] == '0')
				{
					nRGB.x = 255 - nRGB.x; nRGB.y = 255 - nRGB.y; nRGB.z = 255 - nRGB.z;
				}
				SubDiv = Div / WordSize;
				rad = Scores[Word - Wordset].x - (SubDiv * (WordSize - 1)) + (SubDiv * Char);
				rad -= (TAU / s) * 0.5;
				rad = TAU - rad;
				if (c > 1) { ysxCIMG_DRAW_FillFlood(CircI, MidS + cos(rad) * cr * 0.85, MidS + sin(rad) * cr * 0.85, (uint8_t*)&nRGB); }
				else { ysxCIMG_DRAW_FillFlood(CircI, MidS, MidS + sin(rad + PI) * cr * 0.75, (uint8_t*)&nRGB); }
				//if (c > 1) { ysxCIMG_DRAW_Circle(CircI, 3, MidS + cos(rad) * cr * 0.85, MidS + sin(rad) * cr * 0.85); }
				//else { ysxCIMG_DRAW_Circle(CircI, 3, MidS, MidS + sin(rad + PI) * cr * 0.75); }
				//AddText(CircI, MidS + cos(rad) * cr * 0.90, MidS + sin(rad) * cr * 0.90, std::to_string(BinWords[Word][Char]) + "\n" + BinWords[Word], 255, 0, 0);
			}
		}
		uint8_t IgnoreColor[] = { 127, 127, 127 };
		MainImg = ysxCIMG_DrawImageIgnClr(MainImg, CircI, Mid - MidS, Mid - MidS, IgnoreColor);
	}
	return (MainImg);
}
